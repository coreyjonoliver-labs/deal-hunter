1. **CI's scanners must pass before the first push.** The local gate doesn't run them, and both reviewers missed a gitleaks failure and a CodeQL alert.
   - Run gitleaks with CI's flags over `main..HEAD`.
   - Fake secrets in fixtures stay low-entropy (`tok-xxxxxxxxxx`). gitleaks scans every commit, so a realistic one needs a history rewrite.
   - Tests can't use nested quantifiers whose inner class matches the separator. CodeQL scans tests, and a new high alert blocks the merge.

   *repo-specific · log 10-16 gitleaks fixtures, 10-16 py/redos, 10-15 gitleaks config*
2. **Neutralize the dangerous token itself in untrusted text, not a word-boundary match around it.**
   - Every `://` and every mention goes. One prefixed character (`xhttps://`) slips past an anchored match.
   - A removal is replaced with a space, so fragments can't rejoin into markup (`ja**vascript`).
   - For a markup renderer, collapse one-line fields and strip Cc/Cf (bidi) characters, then escape last.
   - Exception: redacting a short identifier (slug, id) does match on token boundaries, so it doesn't garble other text.

   Test prefixed and adjacent forms. *repo-neutral · log 10-15 discord.py:62, events.py:82, summary.py:31, discord.py:123*
3. **Find things in seller-influenced text by a trusted anchor, never an unanchored substring.**
   - Log filters key on the record's origin (module/funcName).
   - Score parsing keys on the model's line-start marker and takes the first number after it.
   - When a parser is tightened, accept the format's common drifts, and log when the old parser would have matched. It fails closed, but visibly.
   - A prompt change that puts listing text on the rating line needs a forged-rating test.

   *repo-specific · log 10-15 events.py:53, launch.py:156 (×2)*
4. **A third-party SDK that reads credentials from env can log them while parsing.**
   - Install the redacting log hook (with `propagate=False`) before any SDK object exists.
   - Keep it for the life of the process, because a timeout-bounded shutdown leaves threads still logging.
   - Validate the credential format yourself, with a fixed error that doesn't echo it.

   *repo-neutral · log 10-16 tracing.py setup (HIGH), tracing.py shutdown*
5. **A deviation from a requirement is written into the spec in the same change.** A deviation only mentioned in the implementer's report leaves the spec stale. This recurred within a day and became a HIGH.

   *repo-neutral · log 10-16 ops-metrics, otel-tracing (both upheld)*
6. **Say what a control actually binds.**
   - A PR's workflows set its own checks.
   - Bare check names accept any app (pin `app_id`).
   - A CodeQL job only proves it ran; blocking needs the ruleset.
   - A guard inside a workflow can't bind a branch that edits it.
   - `permissions.ask` patterns are a speed bump; the boundary is the credential's scope.

   A spec names the channels it leaves open. Each server-side setting gets an acceptance check with a live read-back command. *repo-neutral · log 10-15 graduate-established (×7)*
7. **Fall back or isolate, but never hide the failure.**
   - A refresh that keeps serving the last good value surfaces the error where the consumer will see it (gauge, flag or log), not in state nothing reads.
   - Dropping one rejected item counts as success only if something was accepted.

   *repo-neutral · log 10-16 dashboard.py refresh, 10-15 discord.py:357*
8. **Checks over structured text anchor on the entry they mean.**
   - Match the `images:` item named for the image, not the first key anywhere.
   - Assert the expected match count, so zero matches fail.
   - Prefer a line scan or a real parser to a multi-line regex.
   - A test that skips without its tool proves nothing until CI runs it.

   *repo-neutral · log 10-15 test_deploy.py:25, :68; 10-16 promtool*
9. **Every listener that can bind loopback checks Host, and every credential endpoint checks its transport.**
   - Listeners, scrape endpoints included, accept IP literals plus the configured names.
   - A credential endpoint is https unless loopback or `.svc`, and the host is checked by the parser the transport uses.
   - Headers, userinfo and query strings all count as credentials.

   *repo-neutral · log 10-16 metrics handler, tracing.py _parse*
10. **Egress from the browser's pod is the browser's egress.**
    - Rules name destination pods (namespaceSelector AND podSelector in one `to` element), never a whole namespace.
    - Each allowlisted host is a possible exfiltration channel: document it (including shared-CDN fronting) and add rotating its credential to the compromise steps.

    *repo-specific · log 10-16 tracing component, 10-15 cilium cnp*
